📷 Live webcam AR

The browser streams JPEG frames to a Django JSON API; the server augments every frame and streams the result back. No external services.

🎨 Image filters

Canny edges, cartoon, pencil sketch, thermal heatmap, negative, blur — stackable with any AR mode via classic image-processing ops.
